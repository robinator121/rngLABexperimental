# Optional harmonic centroid heat-bath patch

Date: 2026-10-30. Base commit: `dd96adba23b8100aba9147d71fffc63932fc6b0d`. This is an optional research improvement in the isolated repository copy; the original snapshot is preserved.

## Change and mathematical scope

The local bead Metropolis sampler can move the collective centroid slowly. For the unit harmonic oscillator's primitive finite-bead action,

```text
S(x) = M/(2 beta) sum_j (x[j+1]-x[j])^2 + beta/(2 M) sum_j x[j]^2.
x[j] = c + y[j], sum_j y[j] = 0
S(x) = S(y) + beta c^2/2.
```

Thus the centroid conditional distribution is `Normal(0, 1/beta)` for any bead count. Replacing only the centroid using a fresh conditional draw preserves this specific harmonic target. Springs and internal coordinates are unchanged up to floating-point rounding. The update needs no Metropolis acceptance test. Its benefit to finite-run energy uncertainty and its interaction with the remaining internal modes require the separate Phase II experiment; no coverage or speed claim is established by these regression tests.

## API and source accounting

The helper is exported from `rnglab14.models`:

```python
from rnglab14.models import harmonic_centroid_heatbath

updated_path = harmonic_centroid_heatbath(path, beta, explicit_source)
```

It accepts a finite nonempty one-dimensional path and finite positive beta, returns a new float array, and leaves the input unchanged. It validates the mathematical domain before reading the source. Each successful call consumes exactly 16 audited bytes in one source read. Two big-endian 64-bit words become 53-bit uniforms `u,v` in `[0,1)`. The selected Box-Muller coordinate is

```text
c_new = sqrt(-2 log1p(-u)) cos(2 pi v) / sqrt(beta).
```

The unused sine coordinate is discarded, so there is no hidden transform buffer. `u=0` is finite. No global NumPy/Python random generator is used by the helper.

The simulation option is keyword-only and disabled by default:

```python
from rnglab14.models import PathIntegralHarmonicOscillator
from rnglab14.sources import PCG64Source, StochasticChannels

channels = StochasticChannels(PCG64Source(1), PCG64Source(2), PCG64Source(3))
centroid_source = PCG64Source(4)
result = PathIntegralHarmonicOscillator(beads=16).run_simulation(
    channels, sweeps=12288, burn_in=4096, centroid_source=centroid_source)
```

When supplied, the update runs after every full local Metropolis sweep, including burn-in, and before observables are recorded. The reported acceptance rate still describes local Metropolis proposals. Result metadata identifies `LOCAL_METROPOLIS_CENTROID_HEATBATH_V1`, total updates, exact centroid draw count, manifest, before/after source digests, whether the object aliases a local channel, and `independence_verified=False`.

A separate source argument or a different seed does not establish independent entropy or independent origin. Correct Gaussian conditional sampling assumes healthy IID uniform source words independent of the retained internal coordinates. The API allows source aliasing, labels it, and does not infer independence. If a source is shared, `source_byte_counter_delta` includes its local-sampler consumption as well; `centroid_draw_bytes` remains the specific `16*sweeps` budget. Corrupted or dependent words can invalidate the intended conditional law. The update is specific to this harmonic action, and does not certify full-path mixing or repair arbitrary RNG faults.

With `centroid_source=None`, the transition, all original result fields, source byte counts and source digests match a recorded pre-patch run exactly. Two new metadata fields describe the selected sampler. The complete comparison is retained in `default-behavior-verification.json`.

## Verification

The new test file contains 19 collected cases. It covers the analytically known Box-Muller mapping; harmonic action factorization; preservation of internal coordinates and neighbor differences; nonmutation; zero-uniform behavior; source budget atomicity; invalid beta/path rejection before consumption; explicit-source validation; deterministic replay; Gaussian centroid moments at beta 0.2, 2 and 8; preservation of an independently constructed finite-action Gaussian covariance; default source consumption; optional schedule; and source-alias metadata.

Empirical checks use analytic normal/Wishart standard errors with loose six-standard-error bounds, not estimates generated by the implementation. Each beta uses 12,000 centroid draws, and the independent full-target covariance test uses 10,000 paths. These are regression checks, not a confidence-interval calibration campaign.
