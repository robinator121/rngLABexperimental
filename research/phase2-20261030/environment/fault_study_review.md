# Fault-study independent code review and artifact validation

Date: 2026-10-30. The scientific generation scripts and frozen protocols were read only during this review. No substantive transition, estimator, rolling-window or event-bookkeeping defect was found.

The event rule requires two consecutive rolling CV errors strictly greater than 0.05, and records the second window's endpoint. A run without such an event is right censored; an event confirmed before or at sweep 2048 is counted as preonset. Postonset alert windows are classified by endpoint: the first possible endpoint 2304 spans 1281–2304 and intentionally contains 768 preonset plus 256 postonset sweeps. The three monitors each have a separate nominal 5% whole-run calibration target; there is no combined 5% alarm policy. Actual healthy false alarm rates determine the separate validation gates.

The source monitor sees the explicitly emitted proposal/acceptance inputs, including draws corresponding to energetically downhill proposals; the compiled study consumes a proposal/acceptance pair for every bead. The channel-coupling fault sets acceptance equal to the paired proposal while retaining uniform marginal input laws under the intended healthy PRNG. The acceptance-bias fault shifts and clips the acceptance input. Both changes can invalidate the intended kernel; the centroid update only samples its harmonic conditional component. These results have no implication for independently measured physical entropy.

Two audit improvements were identified before protocol freeze and were implemented by the experiment owner: rechecking the frozen healthy-decision hash/status at execution, and adding paired whole-run alarm-indicator differences. The frozen protocol also now explicitly describes mixed onset windows and separate monitor false alarm targets. Tests were run after these changes and before freeze.

`experiment/test_fault_study.py` provides 14 passing checks (4.77 seconds): direct rolling-window slices and cross-product averaging; strict tolerance; two-window persistence; first-hit censoring and onset filtering; independent whole-action Python transitions compared with the Numba kernel for all four supported fault codes; exact pair transformations and clipping; and the requested exact onset check. Healthy/fault small-kernel paths and source records are identical through index 2047, then source records change at 2048 and trajectories diverge afterward. Full logs/JUnit are in `pytest-fault-study.*`.

`experiment/validate_artifacts.py` independently audits the completed saved campaign without importing `study.py`. It passed **132 checks in 26.98 seconds**. The ten original Phase I files retain their recorded byte counts and hashes. Both fixed protocol hashes, generation code hashes, and prerequisite healthy-decision hash match. All 16 condition NPZ files match their manifest checksums; all seed records match the full SHA256 rule and no distinct stage/role/replica domains collide. Deliberate within-stage paired reuse is allowed and labeled. Uniqueness of derived seed values does not prove independent entropy.

The validator independently derives the finite-bead energy and reconstructs CV energies and BM512 intervals from saved raw traces. All six confirmation/fault primary aggregate coverage rows and every corresponding per-replica estimate, variance and coverage decision match. Across all 512 replicas, each fault condition's raw and source prefix of 2048 sweeps is byte-identical to the healthy prefix. The machine-readable result and line log are `experiment/artifact-validation.json` and `experiment/artifact-validation.log`.

This review verifies implementation behavior, arithmetic and provenance. Statistical interpretation remains restricted to the frozen harmonic workload, update, run length, artificial faults and numerical-tolerance definition.
