# Independent Phase II experiment code review

Reviewed `experiment/study.py` and `experiment/test_study.py` before the confirmation run on 2026-10-30. This was a read-only review; no experiment file was changed. The review found no blocking numerical or statistical error in the proposed fixed configurations.

The local Gaussian action difference, TD formula and CV decomposition match the independently derived reference. Row-vector Gaussian draws multiplied by the covariance Cholesky transpose have the intended covariance. Separate initialization/update/centroid/scan roles and disjoint stage namespaces are correctly implemented. Within-stage seed reuse permits paired comparisons between whole trajectories; it does not multiply the number of independent replicas.

The nonoverlapping batch variance is `sample_variance(batch_means)/number_of_batches` with the appropriate Student-t critical value. The overlapping-batch factor is correct for the variance of the sample mean: the usual long-run variance factor has already been divided by n. The Bartlett estimate uses biased sample autocovariances and a triangular lag window; its normal critical value is explicitly asymptotic. The Geyer code forms adjacent pairs beginning with γ₀+γ₁, truncates before the first nonpositive pair, and monotonizes retained pairs. Its method name and metadata identify it as a sensitivity calculation requiring reversibility for the standard theorem.

The bootstrap resamples matching replica estimates and matching estimated variances, preserving their relationship in the estimated/empirical variance ratio. The between-replica centroid/shape decomposition includes the covariance term. Known-mean pooled ACF calculations use the appropriate decreasing number of lag pairs, with nonstationary starts explicitly marked descriptive.

The proposed R=1024 confirmation gate is meaningful: require both centroid-refresh and IID controls to have exact Clopper–Pearson 95% coverage intervals wholly inside [0.92,0.98], estimated/empirical variance-ratio bootstrap 95% intervals inside [0.75,1.25], and bias 95% intervals inside [−0.01,0.01]. It tests equivalence to tolerances, which is stronger than failing to reject exactly 95% coverage. The gate is a conjunction of frozen requirements. The primary BM512 method is selected before inspecting final replicas; other methods remain descriptive. No post-result threshold changes are justified by this gate.

Nonblocking caveats and guardrails:

1. In the general `variance_methods` function, batch means discard an incomplete trailing batch, while interval centers in `analyze_window` use the full-window mean. Every currently planned retained length is divisible by all included batch sizes, so the current protocol is unaffected. Before admitting arbitrary lengths, require divisibility or return a method-specific mean and effective sample count.
2. Invalid MC-variance estimates count as uncovered intervals, and abstentions are reported. The variance ratio and ESS summaries condition on valid estimates while their empirical denominator uses all replica means. This distinction must remain visible if any abstentions occur. An all-invalid method would also produce nonfinite summary output; it needs a status branch before using this machinery on constant traces.
3. The healthy gate allows a fault study independently of whether the lower confidence bound for the paired mechanism improvement exceeds 0.10. This is a defensible separation: an acceptable healthy baseline can support fault comparisons even if that particular improvement margin is not met. The final narrative must report the mechanism test and healthy-gate decision separately.
4. The simple fault adapters change the stream values supplied to specified algorithmic channels. In particular `ua=up` preserves each marginal uniform distribution while breaking the joint independence assumed by Metropolis; it is an explicitly introduced cross-channel adapter fault. A statement that source diagnostics miss it must identify which marginal and joint diagnostics were actually tested.
5. The code's reuse of two uniforms per proposal is deliberate and permits fixed stream alignment across healthy and faulty conditions. It remains different from upstream's consumption of acceptance words only for uphill proposals. This is documented separation rather than a defect of the healthy target kernel.
6. Gaussian paths produce quadratic, skewed energies; the independent-control t intervals are asymptotic. Their held-out calibration is the relevant finite-sample check. An exact Gaussian start removes transient initialization bias under the modeled PRNG but does not establish universal calibration for other initial states or models.

The tests meaningfully compare the local action against a dense precision expression; the accelerated transition against a separately written NumPy loop; the energies against upstream and exact Gaussian moments; the BM estimate against a known stationary AR(1) finite-sample expectation; the minimum-batch rule; and the centroid shift against target factorization. Passing these tests supports implementation correctness. Independent campaign results are still required to support coverage and causal claims.
