# Historical Phase I pilot artifacts

These seven small artifacts preserve the original scalar PIMC pilot implementation, results, chain summary, coverage figure, methodology note, broad research report and bibliography from 30 October 2026. They predate the independent Phase II investigation and should be read as historical findings.

The original compressed trajectory file and two local detector inventories are not distributed. Absolute private workspace prefixes in documentation copies were normalized to `LOCAL_WORKSPACE` or `LOCAL_HOME`; pilot generation code and numerical result files retain their original content. Links to omitted artifacts point to the data-availability explanation. Original full-file hashes remain in the Phase II baseline verification record.

The pilot's coverage counts were independently verified in Phase II. Its JSON wording “one bead per sweep” is inaccurate: the implementation updates all 16 beads once each. The Phase II [baseline recount](../phase2-20261030/baseline/baseline_verification_report.md) documents this correction, the short-window six-batch caveat and the finite-M reference.

Use [Phase II](../phase2-20261030/README.md) for the new root-cause evidence and calibrated controls. The original pilot was not evidence of RNG-induced failure.
